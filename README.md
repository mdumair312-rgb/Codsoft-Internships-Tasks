# CodSoft Web Development Internship Tasks

Three small front-end projects built during the CodSoft Web Development internship. Each project lives in its own folder and comes in two forms:

| Folder | Original files | Single-file version |
|---|---|---|
| `Codsoft Calculator` | `calculator.html`, `calc-style.css`, `calc-script.js` | `Calculator.html` |
| `Codsoft Landing Page` | `landing-page.html`, `landing-style.css` | `Landing-Page.html` |
| `Codsoft My Portfolio` | `index.html`, `style.css`, `profile.png`, `about-pic.png`, `resume.pdf` | `Portfolio.html` |

## Which one should you open?

**Just want to view a project?** Download only the single file listed in the "Single-file version" column above (e.g. `Portfolio.html`) and double-click it to open in any browser. Everything it needs — CSS, JavaScript, images, and the resume PDF — is embedded inside that one file, so there's nothing else to download and no folder structure to keep together.

**Want to look at or edit the source code?** Use the "Original files" — that's the actual multi-file project (separate HTML/CSS/JS/image files) as it was built, and it's what you'd want to clone the repo for or work on further.

Both versions look and behave identically; the single-file version is just a bundled, portable copy of the same project for easy sharing and viewing.
