# CodSoft Web Development Internship Tasks

Three small front-end projects built during the CodSoft Web Development internship.

## Two ways to use this repo

- **Just want to view a project?** Download the single **`*.html`** file from that project's folder (for example `Portfolio.html`), then double-click it to open in any browser. Everything it needs — CSS, JavaScript, images, and the resume PDF — is bundled inside that one file, so there's nothing else to download.
- **Want the source code?** Use the separate `.html` / `.css` / `.js` / image files in each folder. That's the project as it was originally built, ready to read or edit.

Both versions look and work exactly the same.

## Projects
